# Scene Segment Document Structure (Elasticsearch Mapping Types)

This document represents a single segment of a larger video and is designed for indexing in an Elastic Cloud vector database.

It outlines the standard JSON schema for a Scene Document object, which represents a single, complete state or interaction session within the application. This structure is used for history tracking, persistence, and inter-component communication (especially within `HistorySidebar.tsx` and the `lib` utilities).

---

## 1. Core Identification & Temporal Metadata (The Foundation)

These fields are essential for defining the segment's boundaries and linking it back to the original source.

| Key | Data Type | Description | Elasticsearch Mapping Type |
| :--- | :--- | :--- | :--- |
| `video_id` | `keyword` (String) | Unique identifier for the source video. | `keyword` |
| `scene_id` | `keyword` (String) | Unique ID for this specific segment (e.g., `vid-001-scene-04`). | `keyword` |
| `video_url` | `keyword` (String) | S3/Storage path to the original video file. | `keyword` |
| `start_time_ms` | `long` (Number) | Start time of the scene segment in **milliseconds**. | `long` |
| `end_time_ms` | `long` (Number) | End time of the scene segment in **milliseconds**. | `long` |

---

## 2. Searchable Content & Retrieval Core

This section holds the textual data and the vector required for conversational (semantic) search and high-precision transcript searching.

| Key | Data Type | Description | Elasticsearch Mapping Type |
| :--- | :--- | :--- | :--- |
| `scene_summary` | `text` (String) | A concise, human-readable summary of the scene's primary purpose and mood. (Generated by Gemini Flash). | `text` |
| `full_description` | `text` (String) | Detailed, narrative description of the events, setting, and atmosphere. (Generated by Gemini Flash). | `text` |
| `transcript_phrases` | `nested` (Array of Objects) | **CRITICAL for precision edits.** The word-level (or phrase-level) breakdown of all spoken text. | `nested` |
| `transcript_phrases[].text` | `text` (String) | The word or short phrase spoken. | `text` |
| `transcript_phrases[].start_ms` | `long` (Number) | Start time of the word/phrase (ms). | `long` |
| `transcript_phrases[].end_ms` | `long` (Number) | End time of the word/phrase (ms). | `long` |
| `transcript_phrases[].speaker` | `keyword` (String) | Identifier for the person speaking (e.g., 'Joe', 'Speaker B'). | `keyword` |
| `scene_embedding` | `dense_vector` (Array) | The **vector embedding** of the combined summary and description text. (The key for semantic search). | `dense_vector` |

---

## 3. High-Fidelity Generation Anchors (The Visual Source)

This visual data is crucial for the video-to-video model to maintain high fidelity and temporal consistency.

| Key | Data Type | Description | V2V Generation Role |
| :--- | :--- | :--- | :--- |
| `keyframes` | `nested` (Array of Objects) | A list of key visual moments within the scene segment. | Provides the source image for conditioning the AI model. |
| `keyframes[].type` | `keyword` (String) | `start`, `end`, or `mid` (if required for long segments). | Defines the boundary condition for the V2V model. |
| `keyframes[].time_ms` | `long` (Number) | Precise timestamp of the frame. | Ensures alignment with the video timeline. |
| `keyframes[].s3_url` | `keyword` (String) | S3 path to the **high-resolution** keyframe image data. | Retrieval source for the generative AI. |

---

## 4. Object and Action Data (The Edit Scope)

This data allows for targeted, precise edits based on object manipulation and action replacement.

| Key | Data Type | Description | Edit Targeting Role |
| :--- | :--- | :--- | :--- |
| `objects_tracked` | `nested` (Array of Objects) | Bounding boxes and labels for key trackable items (people, cars, props). | Allows user edits like: "Change the color of the **car** in this scene." |
| `objects_tracked[].label` | `keyword` (String) | Object category (e.g., 'car', 'dog', 'coffee_cup'). | |
| `objects_tracked[].track_id` | `keyword` (String) | Unique ID to track the object across frames. | |
| `objects_tracked[].boxes` | `nested` (Array of Objects) | Array of bounding boxes over time for the object. | |
| `objects_tracked[].boxes[].frame_ms` | `long` (Number) | The specific frame time (ms) where the box is valid. | |
| `objects_tracked[].boxes[].xmin` | `long` (Number) | Top-left x-coordinate of the bounding box (pixel value). | |
| `objects_tracked[].boxes[].ymin` | `long` (Number) | Top-left y-coordinate of the bounding box (pixel value). | |
| `objects_tracked[].boxes[].xmax` | `long` (Number) | Bottom-right x-coordinate of the bounding box (pixel value). | |
| `objects_tracked[].boxes[].ymax` | `long` (Number) | Bottom-right y-coordinate of the bounding box (pixel value). | |
| `actions_detected` | `keyword` (Array of Strings) | Key verbs or activities occurring (e.g., 'running', 'dialogue', 'walking'). | Search filter and content-based edit trigger. |
